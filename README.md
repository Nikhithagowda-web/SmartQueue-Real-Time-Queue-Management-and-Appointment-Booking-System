# SmartQueue - Real-Time Queue Management and Appointment Booking System

A full-stack web application designed to reduce waiting time through online appointment booking, digital token generation, and real-time queue tracking.

## ✨ Features

- Online Appointment Booking
- Digital Token Generation
- User Login and Authentication
- Track Queue Status
- Real-Time Queue Updates
- Staff Dashboard
- Manage Customer Appointments
- First Come, First Served (FIFO) Queue Management
- Supports Hospitals, Banks, Salons and Government Offices

## 🛠️ Tech Stack

- **Frontend:** React.js, HTML, CSS, JavaScript
- **Backend:** Java, Spring Boot, Hibernate
- **Database:** MySQL
- **API:** REST API
- **Development Tools:** Visual Studio Code, Eclipse IDE
- **Build Tool:** Maven
- **Version Control:** Git and GitHub
- **AI Tools Used:** claude

## 🚀 How To Run

### 1. Clone this repository

```bash
git clone https://github.com/Nikhithagowda-web/SmartQueue-Real-Time-Queue-Management-and-Appointment-Booking-System
```

### 2. Run the Backend

- Import the backend project into Eclipse as a Maven project.
- Configure your MySQL database connection.
- Update database credentials in the application configuration.
- Run the Spring Boot application.

### 3. Run the Frontend

- Open the frontend folder in Visual Studio Code.
- Install dependencies:

```bash
npm install
```

- Start the React development server:

```bash
npm run dev
```

### 4. Open the Application

```text
http://localhost:5173
```

## 🎯 Project Objective

To simplify queue management by allowing customers to book appointments online, receive digital tokens, and track their queue without standing in long waiting lines.
